# Stanbic Bank job application form template

A responsive, standalone application form template built with HTML, CSS, and JavaScript.

## View the form

Open `index.html` in a modern browser. The form validates required fields and checks resume file type and size (PDF, DOC, or DOCX, up to 5 MB). It does not send or store application details.

This is an independent template, not an official Stanbic Bank recruitment portal. Use Stanbic Bank's official careers channels to apply for actual roles.
